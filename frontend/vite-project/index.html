Module 1 · Conceptual Foundations

Lakehouse Architecture Foundations

Traditional architectures replicate enterprise transactional data (e.g. SAP ERP accounts) across several stages (Raw landing ➔ Stage ➔ Core warehouse ➔ Data marts). This results in massive cloud compute charges (the Spark Tax) and security vulnerabilities due to scattered copies.

meldra.py Zero-Copy Strategy: Ingest raw CSV, API feeds, or database logs directly to open Apache Iceberg tables stored on your own S3/GCS. Queries run serverless in DuckDB or PyIceberg, keeping the storage completely decentralized and zero-copy.

Module 2 · Connection Configuration

Setting up AWS Glue & GCP BigLake Catalogs

In this module, you connect meldra.py directly to your real storage catalogs. Open the product console and navigate to the Workspace tab:

  • AWS Glue: Provide the S3 warehouse URI (e.g. s3://my-company-lakehouse/), Region, and AWS Access Key credentials.

Applying parameters establishes connection tokens. Any table created hereafter becomes queryable by external engines like Athena or BigQuery.

Module 3 · Ingestion Pipelines

Ingesting Data Tables (Append vs. Merge)

To populate your lakehouse, select the Ingest tab in the main application:

  1. Upload a CSV file (e.g., sample transaction ledger or customer CSV).
  2. Select write mode:
    • Append: Appends new rows to the Iceberg table on every run.
    • Merge: Upserts records on a unique primary key, preventing duplicate entries on S3 automatically.

📖 meldra.ai Product Help Guide

Understand how the Zero-Replication S3 Iceberg platform operates and learn how to integrate programmatically.

High-Level Architecture

meldra.ai is a serverless, zero-replication data lakehouse platform. Instead of copying raw transaction logs or ERP records to external data warehouses, we execute queries directly against open-standard Apache Iceberg metadata stored in your S3 or Google Cloud Storage buckets.

How the Query Cycle Works:

  1. Natural Language Input: Users query the database using plain English.
  2. Context Grounding: The system sweeps the Postgres AGE graph schema to map columns, constraints, and relationships.
  3. Serverless Compilation: The query compiles into optimized DuckDB SQL statements targeting S3 Parquet partitions.
  4. Zero-Copy Execution: Manifest and metadata logs are read on-the-fly, returning results in milliseconds without cluster overhead.

Developer API & Integration Guide

Integrate your data pipelines directly with Meldra. The backend exposes standard REST endpoints for query execution, data ingestion, and catalog schema evolution.

POST /v1/catalog/query
Execute analytical SQL queries against Iceberg tables serverless.
POST /v1/ingest
Ingest CSV data payloads programmatically into partitioned tables with metadata versioning.

Example Python Integration:

import requests

url = "http://localhost:8000/v1/catalog/query"
headers = {"Authorization": "Bearer "}

    "sql": "SELECT dept, SUM(salary) FROM default.employees GROUP BY dept",
    "namespace": "default"
}

response = requests.post(url, json=payload, headers=headers)
print(response.json())

Airflow / Cloud Composer DAG Exporter

Deploy scheduled data validation & compaction pipelines matching this environment configuration.

from datetime import datetime, timedelta
from airflow import DAG
from airflow.operators.python import PythonOperator

default_args = {
    'owner': 'meldra',
    'start_date': datetime(2025, 1, 1),
    'retries': 2,
    'retry_delay': timedelta(minutes=5),
}

def run_meldra_compaction():
    from meldra import MeldraCatalog
    catalog = MeldraCatalog()
    # Optimize small files into manifest clusters on S3
    catalog.optimize_table("default", "employees_sample")

with DAG(
    'meldra_lakehouse_compaction_dag',
    default_args=default_args,
    description='Compacts manifest Parquet files on AWS S3 / Google Cloud GCS',
    schedule_interval='@daily',
    catchup=False,
) as dag:
    
    compact_task = PythonOperator(
        task_id='trigger_compaction_task',
        python_callable=run_meldra_compaction,
    )
